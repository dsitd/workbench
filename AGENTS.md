# Workbench

Архитектура и фактические ограничения: [docs/architecture.md](docs/architecture.md).
Запуск и пользовательские сценарии: [README.md](README.md).

- Основная проверка: `npm run check`.
- Сквозная проверка интерфейса: `npm run smoke` из обычного macOS Terminal.
- Проверка реальной изоляции команд: `npm run sandbox:check` из обычного macOS Terminal.
- API-тесты используют локальные ответы. Не вызывайте платные модели для проверки без прямого разрешения пользователя.
- Сохраняйте границы `main` (Electron), `backend` (сервисы), `agent` (цикл и контекст), `renderer` (интерфейс), `shared` (контракты).
- Каждый объявленный tool call должен получить один результат с тем же ID, включая ошибки и остановку.
- Изменения доступа должны сохранять проверку канонических путей, вложенных прав и приватного каталога приложения.
- Секреты вводит пользователь в настройках модели. Не читайте и не выводите существующие ключи или значения окружения.
- Сборки `release/` локальные и неподписанные. Публикация и подпись требуют отдельного запроса.
